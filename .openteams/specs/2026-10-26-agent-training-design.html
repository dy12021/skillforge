SkillForge · Agent Skill + Web 反馈面板

依据 PROJECT_SPEC、实施计划及用户 2026-10-26 的架构澄清。现有产品规范为已确定设计，次要取舍记录于 docs/DECISIONS.md。

主入口与边界

OpenCode/Codex 等宿主 Agent 读取 skillforge-trainer，使用自己的模型生成任务及候选。CLI / HTTP 将结构化输出提交给工作台，浏览器收集人类判断，Agent 读取持久化反馈继续训练。不要求应用拥有独立模型凭据。

组件与状态

pnpm monorepo；Next.js App Router + React + Tailwind；共享 TypeScript 服务和 Zod；PostgreSQL + Drizzle migrations。不可变文档与原始反馈、幂等命令、乐观锁。真实来源记录为 agent / mock / ollama，无法验证的模型声明明确标注。

可选生成

Agent job 等待宿主提交。应用内 provider job 交独立 worker 执行，失败有状态、有限重试与租约恢复。mock 固定样例明确标示。Ollama 只在显式配置时调用，不调用付费账户。

验证与交付

Phase 0 先验证工程、项目 API 的真实持久化与独立 Web 启动，再进入 Phase 1 首条纵向流程。Vitest 测领域与真实 PostgreSQL，Playwright 测浏览器。未调用真实模型、未完成的 Skill 编译与盲测均保持未验收状态。
